# AI Usage Documentation Series – GitHub Support Repo

This repository serves as the **companion codebase and archive** for the [AI Usage Documentation Series](https://medium.com/@vinitsiriya) published on Medium.

## What you'll find here

- **Code samples** used in blog posts
- **Screenshots** demonstrating AI prompts, outputs, and workflows
- **Branch-wise organization:** Each branch explores a different AI model, workflow, or prompt usage scenario
- **Experiments and proofs** that accompany the articles—so you can reproduce results or try your own variations

## How this repo relates to the blog

All **explanations, step-by-step guides, and lessons learned** are posted on Medium.  
This repo is for:
- Saving and version-controlling all related code
- Storing supporting screenshots and artifacts
- Sharing reproducible experiments and results

> 📖 **Read the full stories and explanations:**  
> https://medium.com/@vinitsiriya

## How to use this repo

- **Browse branches** for specific AI experiments or usage cases
- Refer to the `README.md` in each branch for context and usage instructions
- Fork and try the code yourself, or use it as a starting point for your own work
